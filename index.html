COMMAND LIBRARY

Die Befehle, die man wirklich braucht.

Suche nach Aufgabe, Befehl oder Plattform. Alle Snippets sind für echte Terminals gedacht.

Git

Commit-Historie kompakt

Zeigt die letzten 20 Commits als kurze Einzeiler mit Hash und Nachricht.

git log --oneline -20
Git

Neue Branch erstellen

Erstellt eine neue Branch und wechselt sofort hinein.

git switch -c feature/meine-idee
Git

Status ohne Textwand

Zeigt geänderte, neue und gelöschte Dateien in einer sehr kompakten Form.

git status --short
PowerShell

Wer benutzt Port 3000?

Findet unter Windows die Prozess-ID, die aktuell Port 3000 belegt.

Get-NetTCPConnection -LocalPort 3000 |
  Select-Object LocalAddress,LocalPort,State,OwningProcess
PowerShell

Die 10 größten Dateien

Durchsucht den aktuellen Ordner rekursiv und listet die größten Dateien.

Get-ChildItem -File -Recurse |
  Sort-Object Length -Descending |
  Select-Object -First 10 Name,Length,FullName
PowerShell

CPU-intensive Prozesse

Zeigt die Prozesse mit der höchsten bisher verbrauchten CPU-Zeit.

Get-Process |
  Sort-Object CPU -Descending |
  Select-Object -First 10 Name,CPU,Id
macOS / Linux

Prozess auf Port finden

Zeigt, welcher Prozess Port 3000 geöffnet hat.

lsof -i :3000
macOS / Linux

Ordnergrößen sortieren

Zeigt die Größe direkter Unterordner und sortiert sie aufsteigend.

du -sh ./* | sort -h
macOS / Linux

Heute geänderte Dateien

Findet Dateien unterhalb des aktuellen Ordners, die in den letzten 24 Stunden geändert wurden.

find . -type f -mtime -1
Git

Staged Änderungen prüfen

Zeigt exakt, was beim nächsten Commit enthalten wäre.

git diff --staged
PowerShell

JSON lesbar ausgeben

Liest eine JSON-Datei ein und gibt sie sauber formatiert wieder aus.

Get-Content .\data.json |
  ConvertFrom-Json |
  ConvertTo-Json -Depth 10
macOS / Linux

JSON mit Python formatieren

Prüft und formatiert JSON direkt mit dem Python-Standardmodul.

python3 -m json.tool data.json
Git

Remote-URLs prüfen

Zeigt, wohin Git für Fetch und Push verbunden ist.

git remote -v
PowerShell

Lokale IPv4-Adressen

Listet die lokalen IPv4-Adressen samt Netzwerkadapter auf.

Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object {$_.IPAddress -notlike '169.254*'} |
  Select-Object InterfaceAlias,IPAddress
macOS / Linux

Lokale IP schnell anzeigen

Linux nutzt meist hostname -I; auf macOS fällt der Befehl auf ipconfig zurück.

hostname -I 2>/dev/null || ipconfig getifaddr en0
Git

Lokale Datei zurücksetzen

Verwirft nicht-gestagete Änderungen an genau einer Datei.

git restore -- path/zur/datei
Achtung: lokale Änderungen an dieser Datei gehen verloren.
PowerShell

Letzte Befehle ansehen

Zeigt die letzten PowerShell-Befehle der aktuellen Sitzung.

Get-History | Select-Object -Last 20
macOS / Linux

Letzte Shell-Befehle

Zeigt die letzten 20 Einträge des Shell-Verlaufs.

history | tail -20
