# Terminal Tricks

Eine statische, responsive Website mit echten Terminal-Beispielen.

## Start

Einfach `index.html` im Browser öffnen.

Für lokale Entwicklung mit Python:

```bash
python -m http.server 8000
```

Danach im Browser:
`http://localhost:8000`

## Dateien

- `index.html` – Struktur und Inhalt
- `styles.css` – Design und Responsive Layout
- `script.js` – Suche, Filter, Copy-Buttons und Demo-Terminal

## Deployment

Der Ordner kann direkt auf Netlify, Vercel, GitHub Pages oder einen normalen Webserver hochgeladen werden.
